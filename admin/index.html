文章管理後台

這是賽特神諭的後台入口。使用 GitHub 授權的 Pages CMS 管理文章與圖片，資料儲存在官網 GitHub，無須在網站輸入額外管理密碼。

  1. 點擊下方「開啟文章後台」。
  2. 選擇以 GitHub 登入，首次使用需授權 Pages CMS 存取 seth-oracle/seth-oracle.github.io。
  3. 在專案內打開「攻略文章管理」，就能新增、修改、上傳封面或取消發布。
  4. 按下儲存後，GitHub Pages 完成更新，官網文章便會同步變更。
