# 🛡️ 智慧止盈止損｜自動化資金風控系統

賽特神諭整合即時盈虧監測、個人化資金門檻設定與自動停轉控制，協助使用者建立明確的資金管理規則。

透過**自訂止盈止損條件與自動化執行機制**，減少反覆查看餘額與手動停止轉動的操作負擔，提供更完整的遊戲資金管理體驗。

## 01｜自訂止盈門檻

使用者可依照個人資金規劃，自行設定目標獲利金額。

當系統監測到的累計盈虧達到設定的止盈條件時，將依啟用狀態觸發 ATG 自動轉動停止操作。

**功能特色：**

- 自訂獲利目標金額。
- 即時追蹤相對於起始餘額的盈虧變化。
- 達到設定條件時觸發停轉。
- 透過介面查看目前風控狀態。

## 02｜自訂止損門檻

使用者可自行設定可接受的虧損金額，建立預先規劃的資金使用界線。

當監測盈虧達到止損條件時，系統將嘗試停止 ATG 自動轉動，降低持續進行自動投注的風險。

## 03｜即時盈虧監控

系統以設定時的起始餘額作為參考基準，持續顯示目前盈虧變化。

監控介面包含：

- **起始餘額**：建立本次監測的參考金額。
- **目前盈虧**：顯示相對於起始餘額的資金變化。
- **止盈門檻**：使用者自訂的獲利目標。
- **止損門檻**：使用者設定的虧損上限。

## 04｜自動停轉控制機制

使用者啟用自動停轉後，系統依照設定的資金門檻監測遊戲狀態。

當符合停止條件時，系統會嘗試向支援的 ATG 自動轉動介面發出停止操作。

**此功能僅控制支援的自動轉動操作，不會修改遊戲結果，也不代表能取消已送出的投注。**

## 05｜基本操作流程

1. 登入賽特神諭並進入支援遊戲。
2. 開啟「止盈／止損」功能。
3. 輸入預計的止盈與止損金額。
4. 確認「達到設定金額自動停止」已啟用。
5. 點擊「開始」，啟動資金監測。
6. 透過介面查看盈虧變化及風控狀態。

## 06｜功能注意事項

止盈止損為輔助性資金管理工具，實際停轉效果可能受到遊戲狀態、網路延遲、裝置相容性及自動轉動控制方式影響。

即使觸發停止條件，最後結算金額仍可能超過預設門檻。

**建議使用者預先設定可承受的娛樂預算，並在達到資金上限後停止遊玩。**
