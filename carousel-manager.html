🌳 賽特神諭｜首頁輪播圖管理

在這裡調整每張輪播圖、手機版圖片、點擊後開啟的網址與排序。不用改 HTML。
編輯完成後下載設定檔，再上傳覆蓋 GitHub 的 homepage-carousel.json，網站就會更新。

📁 如何新增自己的圖片？

  1. 先到 GitHub 上傳圖片，圖片建議用英數檔名，例如 banner01.png。
  2. 按下 GitHub 的 Commit changes 完成上傳。
  3. 將圖片網址填成 https://seth-oracle.github.io/assets/banner01.png，也可填手機版圖片網址。
  4. 填入要跳轉的網址，按「下載輪播設定檔」。
  5. 到 GitHub 的輪播設定檔，點鉛筆編輯，將下載的 JSON 內容完整貼上並 Commit changes。

注意：此頁僅在妳的瀏覽器編輯與預覽，不會自行更動 GitHub；要按最後一步儲存才會正式上線。圖片使用公開網址，不用輸入 GitHub 密碼或權杖。
